Icon Placeholders

To use this extension, you need to create icon files:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

You can create simple icons using any image editor.

Recommended: Use a simple "C" letter or Custos logo in these sizes.

For quick testing, you can use placeholder images from:
https://placeholder.com/

Or run these commands to create simple colored squares:
(requires ImageMagick)

convert -size 16x16 xc:#2563eb icon16.png
convert -size 48x48 xc:#2563eb icon48.png
convert -size 128x128 xc:#2563eb icon128.png
